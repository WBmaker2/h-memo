# H Memo 웹앱 실행 링크 라우팅 수정 계획

## 문제

홍보 페이지의 `웹앱 실행` 버튼이 GitHub Pages 루트(`/h-memo/`)를 새 창으로 열고 있어, 앱 라우터가 홍보 페이지를 다시 표시한다.

## 원인

- `AppRouter`는 `#/app` 또는 `#app` 해시가 있을 때만 `WebApp`을 표시한다.
- `LandingPage`의 버튼 URL은 해시가 없는 `https://wbmaker2.github.io/h-memo/`로 설정되어 있다.

## 수정 순서

1. `웹앱 실행` 링크가 `#/app`을 포함해야 한다는 회귀 테스트를 먼저 작성하고 실패를 확인한다.
2. 링크를 배포 기본 경로에 상대적인 `#/app`으로 변경한다.
3. 대상 테스트, 전체 웹 테스트, 타입 검사, 프로덕션 빌드를 실행한다.
4. 로컬 브라우저에서 버튼 링크와 앱 화면 진입을 확인한다.

## 범위

- 홍보 페이지의 웹앱 실행 링크만 수정한다.
- 라우터 구조, Firebase 기능, 다운로드 링크는 변경하지 않는다.
